# IS 14611:2016, multilayered cross-laminated tarpaulins

Full title: "Multilayered cross laminated sheets/tarpaulins/covers/agricultural films – Specification (First Revision)" (S7).

## Duty classes (by GSM)
| Class | GSM band |
|---|---|
| LN, light duty | 60–100 |
| MN, medium duty | 110–150 |
| HN, heavy duty | 200–250 |

## Minimum requirements (secondary source S6; verify against the BIS text)
| Property | Longitudinal | Transverse |
|---|---|---|
| Tensile strength | 250 kg/cm² | 200 kg/cm² |
| Elongation at break | 400% | 300% |
| Tear strength (LN / MN / HN, garbled in source) | ~1200 / 2080 / 3000 | ~900 / 1550 / 2750 |
| Dart impact (unlabelled) | 250 g / 400 g / 700 g | |
| After ageing 168 h at 70 °C | ≤30% decrease in tensile/tear | |
| After UV weathering | ≥40% of original strength retained | |

Units for tear strength are not given in the source. **Do not publish the tear, dart or ageing values** until they are checked against the standard.

The brochure shows only the tensile and elongation minimums, labelled as *category requirements*, not as Crosspaulin test results.
