# Micropaulin brochure design

## Palette (blue and red sampled from the logo, M2)
| Token | Hex | Use |
|---|---|---|
| `--blue` | `#294A96` | "MICRO" in the logo. Table headers, page numbers, icon strokes (hard-coded in `micropaulin/assets/generated/*.svg`) |
| `--navy` | `#172C5E` | Headings, cover proof band, contact band |
| `--red` | `#E12228` | "PAULIN" and "PANKAJ" in the logo. Cover headline accent; kickers use the darker `#C8191F` for contrast |
| `--yellow` / `--yellow-deep` | `#FFD31A` / `#F4C400` | Diagonal stripes, from the banner |

The logo colours are almost the same as Crosspaulin's (both PANKAJ® brands), so the brochure is deliberately a sibling: Montserrat headings and Inter body, as in Crosspaulin. It is told apart by the banner's motif: yellow diagonal stripes under a blue curve (cover band, page-top strip, contact band).

## Logo
`micropaulin/assets/micropaulin-logo.png` is a crop of the banner (M2), 285 × 92 px upscaled 3×, with the off-white JPEG background set to pure white. Colours are untouched. At 92 mm wide it prints at about 80 dpi: **ask for a vector logo**.
